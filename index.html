Threat Model Scope

Attacker Knowledge

White/gray-box access to feature schema, normalization range, and approximate model behavior through API queries.

Perturbation Budget

L-infinity bounded by ε (e.g., 0.03). Features clamped to [0, 1] post-perturbation.

Goal

Evasion: misclassify attack traffic as benign while maintaining feature plausibility.

Feature Constraints

MF (modifiable), RF (recomputable from MF), UF (unmodifiable) enforce domain semantics.
